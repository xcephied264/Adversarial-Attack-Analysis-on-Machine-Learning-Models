# Adversarial-Attack-Analysis-on-Machine-Learning-Models
Conducted an in-depth analysis of adversarial attacks on machine learning models, focusing on evaluating model robustness under crafted perturbations.

Implemented and tested Carlini & Wagner attack to generate adversarial examples and assess their impact on classification performance.

Analysed model vulnerability using key evaluation metrics including accuracy, precision, recall, F1-score, and attack success rate.

Compared model performance before and after attack to identify weaknesses in prediction reliability and decision boundaries.

Produced experimental results demonstrating significant degradation in model accuracy under adversarial conditions, highlighting real-world security risks in AI systems.
